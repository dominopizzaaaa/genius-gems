One-time setup

Because this site has no server, the dashboard fetches your data directly in your browser after you sign in with the Google account that owns Search Console & Analytics. Paste your credentials once — they are stored only in this browser (localStorage), never in the website code.

  1. Go to Google Cloud Console → create a project (e.g. "Genius Gems SEO").
  2. Under APIs & Services → Library, enable: Google Search Console API, Google Analytics Data API, and PageSpeed Insights API.
  3. Credentials → Create OAuth client ID → Web application. Add this page's origin to Authorised JavaScript origins (e.g. https://geniusgems.com.sg and http://localhost:8000). Copy the Client ID.
  4. Also create an API key (used for PageSpeed Insights). You can restrict it to the PageSpeed Insights API.
  5. On the OAuth consent screen, add your Google account as a Test user (keeps it private — no Google review needed).
